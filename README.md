# trabalho_lp
=======
Esse site foi feito como uma ideia simples a partir da empresa da mirella, que é uma das integrantes do grupo. A empresa dela vende joias de prata, então pensamos em fazer uma vitrine online para mostrar os produtos. O site tem uma página principal com a logo e o nome do produto, e também páginas separadas para cada item, como por exemplo o colar coração azul. Em cada página o cliente pode visualizar a imagem da peça, a descrição, o material usado (como prata 925) e o preço. Também colocamos um botão de compra que leva direto para o whatsapp da empresa, facilitando o contato. 

A aplicação foi construída utilizando HTML, CSS e Node.js com o framework Express. Os arquivos das páginas estão organizados na pasta public/pages, os estilos na pasta public/css, e as imagens em public/images.

Para executar o projeto localmente, basta abrir o terminal na pasta do projeto, rodar o comando node index.js e acessar o endereço http://localhost:3000 no navegador.

O objetivo principal deste trabalho foi exercitar a criação de um site estático com rotas básicas, focando em funcionalidade, organização e simplicidade.
